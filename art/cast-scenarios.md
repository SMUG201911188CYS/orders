# 야근조 9인 — 시나리오 · 모에 컨셉 · 개성 설계

v3까지의 문제: 머리색과 소품만 다르고 **아홉이 사실상 같은 사람**이었다. 자세도 표정도 하나였다.

그래서 순서를 뒤집는다. 외형을 먼저 정하지 않고
**시나리오 → 거기서 뽑히는 모에 컨셉 하나 → 그 컨셉이 몸 전체에 만드는 차이** 로 내려온다.

판정 기준은 하나다. **검은 실루엣만 보고 누군지 말할 수 있는가.**
컨셉은 자세·몸짓·소지품·복장 변형에 먼저 나타나고, 얼굴과 눈은 그 뒤를 따라온다.

유지하는 것: 4등신 비율(미오 기준) · 역할군 복장 코딩(조끼 / 벨트 / 파이핑) · 남색 제복 · 픽셀 화풍

---

## 전위 — 앞에 서는 사람들 (형광 조끼 + 청록 견장)

### 01 린 — 겐키
> 심야 배달을 하다 신호소로 왔다. 회의가 길어지면 먼저 일어난다.
> "가서 보면 알아요." 판을 제일 먼저 밟아보고 판단한다.
> 세 번 넘어져도 세 번 다 먼저 도착해 있었다.

| | |
|---|---|
| **실루엣** | 한 발 내디딘 **달리기 직전 자세**. 몸이 앞으로 기울고 가방이 뒤로 튐 |
| 몸짓 | 한 손은 가방끈, 한 손은 주먹 쥐고 뒤로 |
| 복장 변형 | 조끼 지퍼를 열어 젖힘 · 소매를 걷어붙임 |
| 소지품 | 목에 감아 휘날리는 **야광 스카프** · 무릎 반창고 |
| 얼굴 | 이 드러내고 웃음 · 눈썹 바깥이 올라감 · 크고 둥근 눈 |

### 02 하나 — 아네고
> 신호소에서 가장 오래 일했다. 붕괴를 세 번 봤고 세 번 다 마지막까지 남아 있었다.
> 말수가 적다. 대신 자리를 안 뜬다. 신입이 제일 먼저 찾는 사람.

| | |
|---|---|
| **실루엣** | 아홉 중 **가장 넓고 무거운 덩어리**. 어깨에 두른 방염포가 망토처럼 퍼짐 |
| 몸짓 | 팔짱. 무게를 뒤꿈치에 싣고 미동 없음 |
| 복장 변형 | 조끼 위에 **두꺼운 방염포**를 어깨걸이로 |
| 소지품 | 낡은 아날로그 손목시계 · 두꺼운 방염 장갑 |
| 얼굴 | 눈꼬리가 처짐 · 반쯤 감긴 여유 · 살짝 내려다보는 시선 |

### 03 소라 — 도지코
> 사고 처리반 출신. 불을 끄는 게 아니라 **번지는 걸 막는** 훈련을 받았다.
> 최악을 먼저 계산하는 습관이 있는데, 정작 본인은 평지에서 넘어진다.

| | |
|---|---|
| **실루엣** | 소화기를 두 팔로 껴안아 **상체가 앞으로 쏠린 불안정한 축** |
| 몸짓 | 한쪽 발이 살짝 들림 — 지금 막 균형을 잃는 중 |
| 복장 변형 | 조끼가 한쪽만 어깨에서 흘러내림 · 한쪽 신발끈 풀림 |
| 소지품 | 이마의 고글 · 팔과 뺨의 반창고 여러 장 |
| 얼굴 | 눈이 크고 초점이 미세하게 어긋남 · 눈썹 한쪽만 올라감 · 겸연쩍은 웃음 |

## 사수 — 멀리서 먼저 때린다 (황동 벨트 + 파우치)

### 04 유이 — 관찰자
> 관측 기록 20년치를 외운다. 남들이 못 보는 걸 본다고들 하지만
> 본인 말로는 "보는 게 아니라 **기록을 믿는 것**"이다.

| | |
|---|---|
| **실루엣** | 목과 가슴에 **렌즈가 주렁주렁** 달려 상반신 윤곽이 울퉁불퉁 |
| 몸짓 | 몸은 정면, 고개만 옆으로 돌려 먼 곳을 봄 |
| 복장 변형 | 벨트에 기록 카드 뭉치를 부채처럼 꽂음 |
| 소지품 | 한쪽 눈의 **황동 단안경** · 여분 렌즈 · 카드 뭉치 |
| 얼굴 | 단안경 쪽 눈만 커 보이고 반대쪽은 가늘게 뜸 |

### 05 미오 — 졸림 *(기준 이미지)*
> 야간 근무만 3년째. 낮에 제대로 자본 적이 없다.
> 눈으로 안 보고 **소리로 위치를 잡는다**. 그래서 눈을 반쯤 감고 있어도 상관없다.

| | |
|---|---|
| **실루엣** | 어깨에 걸친 **긴 삼각대**가 대각선을 만듦. 전체적으로 축 처짐 |
| 몸짓 | 한 손은 주머니, 등이 살짝 굽음 |
| 복장 변형 | 옷깃을 세워 목을 덮음 |
| 소지품 | 목의 대형 **헤드폰** · 입에 문 에너지 젤리 |
| 얼굴 | 무거운 반쯤 감긴 눈꺼풀 · 눈 밑 다크서클 · 무표정 |

### 06 나기 — 완벽주의
> 측량 담당. 세상을 직선과 각도로 본다.
> 지시서 줄 간격이 안 맞으면 다시 쓰게 한다. 그래서 아무도 나기에게 서류를 안 준다.

| | |
|---|---|
| **실루엣** | 등에 멘 **측량봉이 완전한 수직선**. 몸도 자로 잰 듯 곧음 — 아홉 중 유일하게 안 기울어짐 |
| 몸짓 | 양발을 정확히 붙이고 직립. 팔은 몸통에 딱 붙임 |
| 복장 변형 | 소매 주름 하나 없이 다림. 벨트 버클이 정확히 정중앙 |
| 소지품 | 목에 건 **각도기** · 소매에 나란히 꽂은 펜 |
| 얼굴 | 날카롭게 올라간 눈 · 일직선 눈썹 · 한쪽 눈 찡그림 |

## 지원 — 직접 안 싸운다 (장미 세로 파이핑)

### 07 아오이 — 울보
> 의무 담당. 사람 다치는 걸 보는 게 무섭다.
> 무서운데도 제일 먼저 뛴다. 울면서 처치하고 나중에 혼자 손을 떤다.

| | |
|---|---|
| **실루엣** | 구급함을 **가슴에 꼭 껴안아** 상체가 작게 뭉침. 어깨가 안으로 말림 |
| 몸짓 | 무릎이 살짝 안쪽으로 모임 |
| 복장 변형 | 소매가 손등까지 내려와 손이 반쯤 가려짐 |
| 소지품 | 흰 구급함 · 어깨에 미리 붙여둔 반창고 여러 장 · 손등 붕대 |
| 얼굴 | 눈물 그렁 · 눈가 붉음 · 눈꼬리 처짐 · 입을 앙다뭄 |

### 08 호타루 — 천연
> 발전기 담당. 신호소의 불은 전부 이 아이가 켠다.
> 어두운 걸 싫어해서 쓸데없는 곳까지 켜둔다. 그래서 늘 연료가 모자란다.

| | |
|---|---|
| **실루엣** | 랜턴을 **머리 위로 번쩍** 든 팔이 실루엣 밖으로 솟음. 등의 네모난 발전기 배낭 |
| 몸짓 | 상체가 뒤로 젖혀지고 발끝으로 섬 |
| 복장 변형 | 파이핑 위에 작은 전구 줄을 감음 |
| 소지품 | 손 랜턴 · 머리에 꽂은 작은 전구 · 배낭의 방울 |
| 얼굴 | 감고 웃는 아치 눈 · 볼 홍조 · 입 크게 벌린 웃음 |

### 09 시즈 — 쿠데레
> 서류 담당. 모든 지시서는 이 아이의 도장을 거친다.
> 규정을 어기면 아무 말 없이 기록한다. 화내는 걸 본 사람이 없다.

| | |
|---|---|
| **실루엣** | 한 팔의 **두꺼운 서류 뭉치**와 치켜든 도장. 백발이 무릎까지 내려와 세로로 긴 덩어리 |
| 몸짓 | 완전 정지. 고개만 살짝 기울임 |
| 복장 변형 | 단추를 목 끝까지 채움 · 소매를 정확히 접음 |
| 소지품 | 큰 **고무 도장** · 서류 뭉치 · 목에 건 붉은 인주 케이스 |
| 얼굴 | 가늘고 긴 눈 · 옅은 회색 홍채 · 하이라이트 거의 없음 · 무표정 |

## 실루엣 구분 검사

검은 실루엣만 남겼을 때 무엇으로 구분되는가.

| | 실루엣의 결정적 형태 |
|---|---|
| 린 | 앞으로 기운 몸 + 뒤로 튄 가방 + 휘날리는 스카프 |
| 하나 | 어깨에서 퍼지는 방염포 — 가장 넓은 덩어리 |
| 소라 | 껴안은 소화기 + 들린 한쪽 발 |
| 유이 | 목에 주렁주렁 매달린 렌즈들 |
| 미오 | 어깨를 가로지르는 긴 삼각대 대각선 |
| 나기 | 등의 수직 측량봉 — 유일하게 완전 직립 |
| 아오이 | 가슴에 껴안은 상자 + 안으로 말린 어깨 |
| 호타루 | 머리 위로 솟은 랜턴 팔 + 네모난 배낭 |
| 시즈 | 무릎까지 오는 장발 + 치켜든 도장 |

아홉이 모두 다른 형태다. 색을 다 빼도 구분된다.
